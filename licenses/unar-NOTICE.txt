unar / lsar ライセンス・ソース情報（Karuzip 同梱コンポーネント）
====================================================================

Karuzip は Windows 版 unar 1.8.1 の unar.exe / lsar.exe を改変せず同梱し、
独立した子プロセスとして読み込み・解凍に使用します。書庫作成には使用しません。

対象バイナリ:
  unar.exe  1.8.1
  lsar.exe  1.8.1

版対応の根拠:
  XADMaster の上記 commit は 2013-10-02 の「Bump versions」で、unar.m の
  VERSION_STRING を v1.8.1 としています。universal-detector の上記 commit は
  同日の Windows build 修正であり、公式な commit 間対応表が存在しないため、
  評価時点で最も蓋然性の高い対応点として記録します。
